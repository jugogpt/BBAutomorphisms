# Bivariate Bicycle Code Automorphisms: computational verification
Supporting work from paper on Automorphisms of BB error correction codes. Pythono code for computationally verifying the forward problem (given polynomial pair (A,B) -> Aut(R)) and inverse problem (given target Aut(R) or encompassing subgroup H -> (A, B)).
